# ticket-booking-platform
A Platform where users browse events, browse seats, pay and get notified.

## Tech Stack
- Backend : Java 21 , Spring boot, PostgreSQL
- Frontend : HTML, CSS, JavaScript, TypeScript
- Tools : Git, Postman, Docker(later)

## Goals
- Learn full-stack java development and Backend system design
- SDLC agile model
- SOLID principles
- ACID properties
- CAP Theorem
- API design

## Status
- Sprint 1: Event List, event details, admin creates event
